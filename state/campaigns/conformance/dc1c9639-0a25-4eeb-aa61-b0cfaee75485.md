## Hypothesis

The section is in `gaps` because its audit predates any code at all (it is one
of the six still stamped `03:47:22`, which also claims `vendor/` does not exist
on disk). Nothing about it is blocked: `rope` already carries the
`PointUtf16`/`OffsetUtf16` dimensions and the clip functions the section names
as the mechanism, so the module is a wrapper that adds the *exactness* rope
deliberately does not have — rope clips, and a clip that silently moves a
position is the failure mode this section exists to prevent.

Expect: `shared::proto` seeded with `PositionEncoding`, `WirePosition`,
`Error::Encoding`, and a property test in `crates/shared/tests/` comparing the
conversions against a naive `&str` reference over text with astral-plane
characters.

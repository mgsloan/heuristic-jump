are blocked on the same missing artifact, and it is this one. `core.md` §1

the dependency direction forbids the reverse". So:

- §1's `Location`/`Query` cannot be written: their fields are those types.
- §2's `DocumentSnapshot` holds a cloned `Rope`.

  is manageable is rope's `OffsetUtf16`/`PointUtf16` summary dimensions.
- §10's first two suites test §2 and §3.

Two of the audit's own `found:` lines say it outright — "vendor/ … does not
exist on disk" and "the re-exported rope newtypes are not expressible". The
remaining gaps (§4 file enumeration, §5 deadlines) each need a dispatch site,
which needs the seam, which needs this.

It is unblocked for the first time as of this campaign: decision
`conformance-002` was answered and a human placed the root `LICENSE-*` texts,
which `deps.md` §14 makes a precondition of the copy — `vendor/rope` arrives
carrying `LICENSE-GPL -> ../../LICENSE-GPL`.

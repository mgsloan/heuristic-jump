## Hypothesis

The conversion is ordinary code that has been blocked on nothing: every piece
it needs already exists (`WirePosition::encode`, `ProjectView::read`,
`Location::{uri,range}`), and the reason it was never written is that
`dispatch` had no encoding parameter and nobody had a reason to add one.

What the section says makes it free — "at the moment the handler returns,
every target file's text is already in the view's cache" — is the one thing
that is *not* true today: `conformance-005` ruled out the per-query read
cache, so each target file is a fresh disk read. Expected to be a comment
rather than a blocker; adding a cache here is what that ruling forbids.

Expected to surface: `56ccb86901` is Class A, and the honest resolution is to
narrow the premise rather than delete it. `measure_core` does put a *position*
on a wire; what it never does is put a handler's *answer* on one, which is the
conversion the section is about and the reason it lives in `driver`.

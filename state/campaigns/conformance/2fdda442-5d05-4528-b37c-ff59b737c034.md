## Hypothesis

`ServerId` has no producer because `ServerId(&'static str)` cannot be built
from a runtime command name without a table of the servers that exist, and no
such table has been written. `servers.toml` is that table already — it is the
canonical server matrix and is in no loop's write list — so the work is a
resolver in `shared` over a copy of that list, a test that the copy and the
canonical file agree, and both call sites (driver at startup, `measure_core` on
the replay path) going through it.

Expected to be structural rather than asserted: making `ServerProfile`'s field
private leaves `standalone()` and the two `proxying_*` constructors as the only
routes, so "the identity was discarded" stops being expressible.

## Hypothesis

The section is unjudged because its work splits across two owners and only one
of them is a loop's to write: `measure_core` produces `--records`, and
`harness/measure` digests it (`core-001`, open, `harness/**` denied to every

## Outcome

Confirmed, on the half a loop owns.

The templates gap was stale: `Table::template()` and its test predate the
campaign by hours and the audit's `last_audited` for the section predates the
commit by 26 minutes. Nothing changed there.

The unjudged section gained the two claims a replay's artifacts have to
support and nothing was holding:

- **The records file and the table are the same run counted twice.** Every
  counter in `--format json` — `queries`, `committed`, `abstained`, `failed`,
  `match_top1`, `match_contained`, `mismatch`, per stratum — is re-derived
  from the `--records` JSONL and compared. This is what makes the digest's
  "share of that stratum" a number rather than a second opinion, and it is
  the reconciliation that catches a records file that was filtered, a table
  that double-counted, or a `stratum_prior`/`stratum_final` swap.
- **A group can name a case a person can open.** All six of the section's
  sample fields are assembled from the records file and the frozen corpus:
  repository and relative file from `uri` through `DocumentUri::to_file_path`,
  the identifier from the positions file joined on `(file, offset)`, the line
  by counting newlines to the offset in the checkout, and both answers from
  `heuristic_locations`/`lsp_locations`. The fixture is two files with
  *different* text at the same offsets, so a join on `offset` alone names the
  wrong identifier and fails.

What is left is entirely `harness/measure`, which is `core-001` and open. It
is not a gap a loop can close: `harness/**` is denied, correctly.
